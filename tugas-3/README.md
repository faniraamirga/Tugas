# Tugas-3 Ekonomi Kreatif: Rantai Nilai Kopi Arabika Latimojong

- `Tugas-3_Rantai_Nilai_Kopi_Latimojong.docx`: dokumen yang diunggah ke SIAKAD (isi NIM dulu).
- `rantai_nilai_kopi_latimojong.png`: diagram rantai nilai + grafik nilai tambah.
- `diagram_rantai_nilai.py`: skrip pembuat diagram; ubah angka di daftar `aktor` lalu jalankan ulang.
- `buat_dokumen.py`: skrip penyusun dokumen Word (butuh `python-docx`).

Jalankan: `python3 tugas-3/diagram_rantai_nilai.py && python3 tugas-3/buat_dokumen.py`
