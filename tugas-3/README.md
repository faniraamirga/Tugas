# Tugas 3 Ekonomi Kreatif: rantai nilai kopi arabika Latimojong

- `Tugas-3_Rantai_Nilai_Kopi_Latimojong.docx`: dokumen untuk diunggah ke SIAKAD (isi NIM dulu).
- `Tugas-3_Rantai_Nilai_Kopi_Latimojong.pdf`: versi PDF dari dokumen yang sama.
- `rantai_nilai_kopi_latimojong.png`: diagram rantai nilai dan grafik nilai tambah.
- `diagram_rantai_nilai.py`: skrip pembuat diagram; ubah angka di daftar `aktor` lalu jalankan ulang.
- `buat_dokumen.py`: skrip penyusun dokumen Word (butuh `python-docx`); angka tabel ada di daftar `baris`.

Jalankan: `python3 tugas-3/diagram_rantai_nilai.py && python3 tugas-3/buat_dokumen.py`

Teks dokumen ditulis mengikuti skill humanizer di `.agents/skills/Human/SKILL.md`.
